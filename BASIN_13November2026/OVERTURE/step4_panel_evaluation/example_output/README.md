# Historical Step-4 example outputs

These TSVs are retained from the package's earlier broad method-development
sweep and therefore contain drop fractions outside the current production
defaults (including `median_drop00`, `median_drop05`, and values through
`median_drop70`).

As of the 2026-09-23 patch, new Step-4 runs default to the HARMONY production
set `0.10, 0.20, 0.35, 0.50`. A broader `DROP_LIST` can still be supplied
explicitly when reproducing exploratory panel-development analyses.

The historical TSVs were not regenerated by the patch because the validation
bigWigs used to produce them are not distributed in this package.
